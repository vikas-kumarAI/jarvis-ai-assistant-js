# 🤖 Jarvis AI Assistant (JavaScript)

A browser-based voice AI assistant built using JavaScript that listens to user commands and responds using speech synthesis.

---

## ✨ Features
- 🎤 Voice recognition (Web Speech API)
- 🔊 Text-to-speech responses
- 🧠 Command-based interaction
- 🌐 Runs directly in the browser

---

## 🛠️ Technologies Used
- JavaScript
- HTML5
- CSS3
- Web Speech API

---

## 🚀 How to Run
1. Open `index.html` in **Google Chrome**
2. Allow microphone access
3. Click start and speak 🎙️

> Note: Works best in Chromium-based browsers.
